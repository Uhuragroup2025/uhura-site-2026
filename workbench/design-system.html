Uhura Theme System · Theme Exit Governor

Owner actual: Home bundle + theme-exit-governor.js
Experimental

No consumir todavía: el cambio continuo dark/light depende de IDs, copy y del canvas fijo dentro del Home heredado. La API objetivo será data-theme-system + data-theme="dark|light". Ambient Field crea atmósfera dentro de una sección; Theme System coordina el contexto cromático de la página.
